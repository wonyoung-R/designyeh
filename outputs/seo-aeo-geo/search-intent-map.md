# 페이지별 고객 질문과 역할

2026-09-19. 검색량·검색 순위 추정 없음. 현존 경로·승인된 홈페이지 중심 소개에 맞춘 맵이다.

| 페이지 | 고객 질문 / 역할 | 핵심 메시지 | 다음 경로 |
|---|---|---|---|
| `/` | 무엇을 맡길 수 있고 어떤 결과물을 볼 수 있나? | 홈페이지 기획·디자인·제작·인계, 작품으로 확인 | `#works` → `/homepage-production/` → `/contact/` |
| `/homepage-production/` | 어디까지 포함되며 무엇을 준비하나? 기존 사이트도 가능한가? | 준비 자료·포함/제외·6단계·수정/인계 기준 | `#service-works`, `#faq`, `/pricing/`, `/contact/` |
| `/brand-identity/` | 로고를 유지하거나 홈페이지와 함께 의뢰할 수 있나? | 권한 확인, 로고·색상·서체·웹 적용의 합의 범위 | `#service-works`, `#faq`, `/homepage-production/`, `/contact/` |
| `/operations-automation/` | 내 업무가 자동화 대상인가? AI가 꼭 필요한가? | 규칙·예외·연동 환경 판단, 비AI 대안, 익명화 예시 | `#faq`, `#service-works`, `/contact/` |
| `/pricing/` | 견적 변수, 포함/제외, 유지관리 비용은? | 9월 17일 승인 조건, 기본 범위와 별도 계약 구분 | `#landing`, `#revisions`, `#maintenance`, `/contact/` |
| `/contact/` | 어떻게 연락하며 무엇을 보내야 하나? | 현재 상황·목표·기능·조건, 외부 이메일/채팅, 민감정보 금지 | 기존 mailto·카카오 링크, 다른 서비스 준비 안내 |
| `/#works` | 각 작업에 무엇을 구현했나? | 기존 공개 역할·구현 내용 보존, 효과 수치 추가 없음 | 원래 외부 작업 사이트 + 홈페이지 제작 범위·과정 |
| `/#approach` | 어떻게 일하는 스튜디오인가? | 사업 분위기와 정보·문의 동선 | `/#process`, `/contact/` |
| `/about/`, `/portfolio/` | 과거 주소로 소개·사례 찾기 | 각각 홈 approach·works 별칭 | 기존 JS 이동 + no-JS 링크 |
| `/404.html` | 없는 주소에서 돌아가기 | 오류 안내와 실제 홈 링크 | `/` |

가격은 가격 페이지, 범위·준비·예외는 해당 서비스, 연락 준비는 문의에 둔다. 홈 FAQ를 모든 서비스에 복제하지 않았다. 자동화 FAQ 한 항목은 기존 서비스 진단 내용을 짧은 직접 답변으로 묶었다. 고객 정보·무료 진단·정해진 납기·새 서비스 제공 조건을 추가하지 않았다.

독립 사례 상세, 소개 상세, 정책 상세, 글/가이드 목록·상세, 페이지네이션은 발견하지 못했다. 작품은 홈의 기존 7개 앵커, 정책은 가격 및 문의의 안내로 분류한다. 존재하지 않는 다운로드나 메일 자동 발송을 만들지 않았다.
