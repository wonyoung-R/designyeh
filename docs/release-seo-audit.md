# Release SEO / AEO / GEO audit

Reviewed 2026-09-19 against the repository and live Chrome responses. This revision describes local changes, not deployment. The site has six canonical marketing pages on `https://dsgnyeh.art`: `/`, `/pricing/`, `/contact/`, `/homepage-production/`, `/brand-identity/`, and `/operations-automation/`. Local titles and descriptions are unique across those pages. Root Organization and WebSite JSON-LD retain stable production IDs and the public contact email, `creativebyyeh@gmail.com`. The deprecated LocalBusiness subtype ProfessionalService and unsupported service-area/language claims were removed locally; no location was invented.

Service pages emit linked Service, WebPage, BreadcrumbList and FAQPage JSON-LD, referencing the root agency as provider. Visible FAQ content and structured questions and answers use the same `service.faq` data; the service definition is also visible. JSON-LD serialization escapes less-than characters.

`robots.txt`, sitemap and the existing `llms.txt` were preserved byte for byte. The wildcard rule currently allows search and training crawlers; these have different roles and any policy change requires separate approval. The sitemap lists only the six canonical pages. The existing llms file is optional, not a special requirement for AI visibility; no new file or claims were added. Public project labels and original images were preserved. Further case-study expansion requires evidence of roles and dates, rather than treating previously published content as independent proof.

Legacy about and portfolio routes still use `window.location.replace` to `/#approach` and `/#works`. Their initial documents remain noindex/follow with fallback headings and links when JavaScript is disabled. The exported 404 HTML contains noindex alongside inherited index directives; a genuinely missing production URL returned 404. No robots directives were changed. Direct HTTP apex access returned 200 without an HTTPS redirect, while www and slashless routes redirected once to the canonical host/path. Hosting changes remain approval items.

The homepage keeps its current hero, gallery and website-first positioning, with one practical scope sentence. Service pages now use the appropriate inquiry labels and preparation instructions. Case cards link to scope/process, services link to one another, and the automation FAQ explains how suitability is assessed. Contact retains the exact email/chat destinations and clarifies that website package terms do not apply to other services.

Current checks and limitations are recorded in [the task QA report](../outputs/seo-aeo-geo/qa-report.md), with [URL inventory](../outputs/seo-aeo-geo/page-inventory.csv), [implementation map](../outputs/seo-aeo-geo/implementation-map.md) and screenshots. The 65 repository tests and lint passed. Before/after production exports used webpack because Turbopack hit an environment port-permission error. No dependency audit, Search Console submission, real-device validation, external inquiry delivery or deployment was performed in this review. Historical verification counts are not reused as current evidence.

Crawl access, metadata, structured data and `llms.txt` do not guarantee indexing, rankings, rich results, AI visibility or citations.
