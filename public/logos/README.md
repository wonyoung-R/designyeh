# Project logo sources

Retrieved from the public project websites on 2026-09-16 for the designYEH portfolio.

- `designluka-wordmark.png`: https://designluka.co.kr/static/media/luka-slogan.0c9dd707cf413b3ee1a3.png
- `dcare.png`: https://dcarecenter.kr/images/logo_main_blk.png
- `gritlab.png`: https://grit-lab.kr/gritlab-logo.png (the original response is JPEG despite its filename)
- `hoopnote.png`: https://www.hoopnote.kr/img/logo-mark.png; paired with the site's lowercase wordmark.
- `mavs.svg`: the MK square and MAVSKR text wordmark from https://mavs.kr/, reproduced from its header markup using its Courier New fallback. The site's favicon is a different mark and is not used.

Raster originals are retained. The carousel uses CSS filters to present the marks in monochrome. No external asset requests are needed to display them.
