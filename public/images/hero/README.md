# Hero backgrounds

Generated on 2026-09-17 with the built-in image_gen tool. Reference: https://www.youtube.com/watch?v=pAwhb9yiVWw — website hero examples with left-aligned copy and original photographic imagery on the right. The video frames and depicted people were not reused as site assets.

Three original decorative photographs: studio-conversation, studio-making, studio-space. Each is stored locally as desktop and mobile WebP files in this directory. Conversion and proportional resizing use Sharp; PNG originals remain in the generation output directory. The site crossfades these backgrounds every eight seconds and displays only the first scene for reduced-motion preferences.
